# Spec Questions — คำถามที่ยังตอบไม่ได้

เตรียมไว้ก่อนเข้า WS-02 Lab (Requirements & API Design) เพื่อปิดช่องว่างก่อนเขียน
Acceptance Criteria — ถ้าไม่ตอบเอง AI จะเดาแทนให้ ซึ่งมักเดาผิด

## 1. นักศึกษาจองห้องล่วงหน้าได้กี่วัน?
จองได้ไกลสุดกี่วันข้างหน้า (เช่น จองได้แค่ภายในสัปดาห์นี้ หรือจองข้ามเทอมได้เลย)?

## 2. ยกเลิกการจองได้ถึงเมื่อไหร่?
ยกเลิกได้ตลอดเวลา หรือมีเงื่อนไขเวลาขั้นต่ำก่อนถึงเวลาจอง (เช่น ต้องยกเลิกก่อนเวลาเริ่ม 1 ชั่วโมง)?

## 3. นักศึกษา 1 คนจองพร้อมกันได้กี่ห้อง/กี่ slot ต่อวัน?
มีลิมิตกันไม่ให้คนเดียวยึดห้องรวบหมดไหม (เช่น จองซ้อนกันได้สูงสุดกี่ booking ที่ยัง active อยู่)?

## คำตอบ (ตัดสินใจใน WS-02 Lab)

| คำถาม | คำตอบ |
|---|---|
| 1. จองล่วงหน้าได้กี่วัน? | ไม่เกิน 14 วัน |
| 2. ยกเลิกได้ถึงเมื่อไหร่? | ต้องยกเลิกก่อนเวลาเริ่มอย่างน้อย 1 ชั่วโมง |
| 3. จองพร้อมกันได้กี่ booking? | active booking สูงสุด 3 รายการต่อคน |
